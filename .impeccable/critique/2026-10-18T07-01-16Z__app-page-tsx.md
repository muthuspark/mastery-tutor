## Overall impression

The link works well as quiet secondary navigation. Its biggest opportunity is clearer pointer feedback, rather than greater prominence.

## What works

- The top-right location is familiar and keeps attention on learning.
- Its measured target is 91.83 × 44px on desktop and mobile. Text contrast is 16.54:1, and the 2px crimson keyboard outline has a 3px offset.
- Enter, pointer click, and touch tap reach `/settings`, where the heading confirms the destination. Mobile has no horizontal overflow.

## Priority issue

**[P2] The hover state does not render.** The source requests muted text and a crimson hover color, but the browser renders charcoal `#1a1a1a` in both states. The unlayered `a { color: inherit; }` rule in `app/globals.css` overrides the layered Tailwind color utilities on the anchor in `app/page.tsx`.

**Why it matters:** With no underline and no hover change, the link looks like static header text. Placement and cursor provide clues, but interaction confirmation is weak.

**Fix:** Set default and hover colors directly on `.home-settings` in the existing stylesheet, and show an underline on hover. Preserve the current keyboard outline and target size. Suggested command: `impeccable polish`.
